React Product Cards
Objective:
The objective of this experiment is to create a simple React application that displays a list of products using reusable components and props.

Overview:
In this experiment, a React interface is built by combining a parent component and reusable child components. The parent component maintains a list of products in an array and dynamically renders them on the page by mapping over the array. Each product is passed as props to a reusable card component that is responsible for displaying product details such as name, price, and stock status. Inline styles are applied to give quick visual structure to the cards.

Key Files:
App.jsx acts as the root component of the project. It initializes the product list and renders multiple product cards.

ProductCard.jsx defines the reusable card component that accepts props and displays individual product details.

Header.jsx is a simple reusable component that displays the page title.

App.css and other supporting files come from the Vite boilerplate setup for styling and configuration.

Tech Stack:
The project is built using React with Vite scaffolding. It uses modern JavaScript features with ES module imports and exports. ESLint is included for basic code quality checks.

Features Demonstrated:
This experiment demonstrates several core concepts of React:

Component composition by combining a parent container with child components.

Passing data to child components through props.

Rendering dynamic lists using the JavaScript map() method.

Styling React components using inline CSS objects.

Organizing the application into modular files for better maintainability.

How to Run:
The app can be executed by opening a terminal in the project folder, installing dependencies using npm install, and starting the development server with npm run dev. The application will then be accessible in the browser at the URL provided by the terminal output.

Learning Outcomes:
From this experiment, students will learn how to:

Structure a React project with separate components.

Build reusable UI components that can accept and display data via props.

Dynamically render content based on arrays or datasets.

Apply inline CSS styles within React components.

Maintain clean and modular code following React’s component-driven architecture.

Test Cases:
The application can be tested by checking whether the correct number of product cards is displayed for the given product array, verifying that changing product properties such as price or status reflects correctly in the UI, ensuring that adding a new product automatically renders a new card, and observing that an empty product array results in no cards being displayed. The header component can also be tested by updating its title prop and verifying that the change appears instantly.

Possible Extensions:
This experiment can be extended by loading products from an external API or JSON file instead of a hardcoded array. Additional features such as search, filter, and sorting can be added to enhance usability. Inline styles can be replaced with more scalable styling approaches like CSS Modules, Styled Components, or Tailwind CSS. Interactivity features such as “Add to Cart” buttons or stock availability indicators can also be implemented. For more advanced use cases, the product data can be connected to a backend database to manage products dynamically.
